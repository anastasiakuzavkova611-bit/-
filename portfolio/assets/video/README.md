# Видео для кейсов

Сюда загружаются видеофайлы, которые вставляются в страницы кейсов
вместо серых заглушек.

## Как загрузить видео через GitHub (без командной строки)

1. Открой репозиторий на github.com и вверху слева переключись на ветку
   **`claude/portfolio-homepage-55oadn`** (важно — грузить именно в неё,
   чтобы я потом смог забрать файл).
2. Зайди в папку `assets/video/`.
3. Нажми **Add file → Upload files**.
4. Перетащи сюда видеофайл (или несколько).
5. Внизу нажми **Commit changes** — коммить в ту же ветку
   `claude/portfolio-homepage-55oadn`.

После этого напиши мне — я подтяну файлы и вставлю их в кейс.

## Формат и имена

- Формат — **MP4 (кодек H.264)**: открывается во всех браузерах.
- Ограничение GitHub на загрузку через сайт — **до 25 МБ на файл**.
  Если видео тяжелее, его нужно сжать (например, до 720p) — скажи, помогу.

Предлагаемые имена файлов (по ним я пойму, куда какое видео вставить):

| Файл                 | Куда вставится                          |
|----------------------|-----------------------------------------|
| `revolut-demo.mp4`   | Большая демка в hero (вверху кейса)      |
| `interview-1.mp4`    | 1-я запись в разделе «Глубинные интервью»|
| `interview-2.mp4`    | 2-я запись                               |
| `interview-3.mp4`    | 3-я запись                               |
| `interview-4.mp4`    | 4-я запись                               |

Имена можно и другие — тогда просто напиши, какой файл куда.

## Превью (poster)

По желанию можно положить сюда же картинку-превью (первый кадр), которая
показывается, пока видео грузится, — например `revolut-demo-poster.jpg`.
Если её нет — ничего страшного, сделаю превью сам.
